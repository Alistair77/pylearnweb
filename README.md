# PyLearnWeb

A landing page template for a Python-learning platform — built with React 19, Vite, Tailwind CSS v4, and Framer Motion. Features a live Three.js hero scene, an interactive product bento grid, tilt-card team section, and a dark glassmorphism floating navbar.

## Stack

- React 19 + Vite
- Tailwind CSS v4
- Framer Motion
- @react-three/fiber + drei (3D hero scene)
- shadcn/ui + Radix primitives

## Getting Started

```bash
npm install
npm run dev      # start dev server
npm run build    # production build
npm run lint      # eslint
```

## Notes

This is a template/portfolio project — all copy, team members, and stats are placeholder content, not real data.
